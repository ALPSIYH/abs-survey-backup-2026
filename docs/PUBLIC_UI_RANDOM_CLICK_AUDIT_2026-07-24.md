# 公開版介面亂點審查

日期：2026-07-24  
範圍：公開版工作台、對話分析、題庫、結果、分析紀錄、語言與字體  
方法：三位獨立測試者分別進行對話狀態、研究工作台、前端互動與狹窄視窗測試；另由主流程核對程式行為及本機修正版。

## 本輪已修正

### 1. 工作台的助理展開按鈕

- 舊行為：在工作台內擴大右欄，壓縮中央分析區；在對話頁幾乎沒有實際作用。
- 新行為：工作台只顯示「前往對話分析」按鈕，點擊後直接切換到對話分析頁。
- 同時移除已失去用途的 `assistantWide` 狀態與相關版面規則。

### 2. 新問題與新對話的操作語義

- 兩個功能都有必要，但不再使用單獨的 `+` 與回轉箭頭。
- 工作台精簡助理不顯示這兩個動作。
- 完整對話頁改成帶文字的「新問題」與「新對話」按鈕。
- 「新問題」保留既有對話與上一個結果，只清除目前題目脈絡；處於空白新問題時按鈕會停用，避免連續插入重複分界。
- 「新對話」建立全新的對話工作階段並清除目前對話內容及對話結果。
- 頂部「新問題」與對話建議中的「分析另一個題目」已統一為相同行為。

## 下一輪優先處理

### P1-1 初次載入存在 React hydration 錯誤

兩位測試者在重新載入公開站時穩定捕捉到 React `#418`。畫面目前仍能使用，但這代表伺服器與瀏覽器第一次輸出的內容不一致，可能造成閃爍、重建畫面或狀態異常。

建議：

- 統一語言、字體及工作模式的伺服器初始值。
- 等瀏覽器掛載完成後再套用本機保存設定。
- 加入「重新載入後無 console error」的瀏覽器測試。

### P1-2 快速切換會污染分析紀錄

快速依序切換拆分方式或回答順位時，每一個中間狀態都可能被保存，分析紀錄因此出現使用者並不想保留的過渡結果。

建議：

- 分析查詢保留短延遲合併。
- 分析紀錄另設較長的穩定延遲，只保存停止操作後的最終狀態。
- 以完整分析設定與結果雜湊去重。

### P1-3 結果標題使用「要求範圍」而非「實際範圍」

例如 q177 選擇全部六波時，W1、W2 沒有資料，圖表只有 W3–W6，但標題仍顯示「6 個波次」。

建議：

- 標題顯示「4 個可用波次」。
- 另列「W1、W2 無資料」。
- 工作台與對話結果共用同一個實際涵蓋範圍摘要器。

### P1-4 對話中的國家範圍回覆洩漏內部代碼

多選國家後，回覆可能顯示「1、3、7」，而不是 Japan、South Korea、Taiwan。

建議：

- 所有對話回覆在呈現前統一經過 country code 到公開名稱的映射。
- 內部 ID 只留在命令與資料層。

### P1-5 重新整理會遺失主要工作狀態

語言、字體與頁面模式會保留，但題目、分析範圍、分析方式、結果、分析紀錄與對話都會消失。

建議：

- 先使用 session storage 保存目前草稿、結果識別與對話識別。
- URL 至少保存頁面模式與題號。
- 後續再決定是否提供可分享的完整分析網址。

### P1-6 大範圍結果缺乏資訊量上限

- 全部國家 × 全部波次的四分位數圖可高達約 8,000–8,500px。
- 多選題組可一次顯示大量分面與數十個選項。

建議：

- 大於一定分面數時，只顯示第一組或目前選定組。
- 提供國家／波次分面選擇器與「顯示更多」。
- 四分位數改用緊湊區間點圖，避免一組一張長卡片。

### P1-7 題目推薦排序仍過度依賴寬泛關鍵詞

「日本的民主程度在各波平均值」會先出現 Meaning of Democracy 子題，較直接的民主程度題目排在後面；中國影響力搜尋也會混入部分美國或一般 influence 題目。

建議：

- 實體條件、測量對象與分析意圖進入主要排序。
- 主題或共同詞只負責召回，不應主導前幾名。
- 前 3–5 題顯示高信心候選，其餘放入「廣泛相關」。

## 可排在其後

### P2-1 搜尋與分類交集為零時只有空白

加入空狀態，明確說明目前搜尋與分類沒有交集，並提供「清除搜尋」與「重設分類」。

### P2-2 多選題載入時短暫顯示 0 個回答槽

資料尚未回來時顯示「正在載入回答槽」，不要把暫時狀態呈現成資料事實。

### P2-3 大型量表與資料表缺少瀏覽工具

- q37 完整量表約 353 列。
- 大範圍統計結果可達數十至數百列。

建議加入固定表頭、表內捲動、搜尋或分頁；下載功能可放在後續。

### P2-4 無資料組合清單難以掃讀

不要把數十個國家－波次組合塞在同一段文字；改成依國家分組，列出各國缺少的波次。

### P2-5 狹窄視窗的對話輸入框不在首屏

640px 與 820px 寬度下，使用者需要越過空白結果區與介紹才能輸入。無結果時應縮短結果空狀態，或讓輸入區更靠前。

### P2-6 部分中文分析紀錄仍出現英文統計名稱

統一分析紀錄與結果標題使用相同的中英文統計名稱表。

## 已確認正常

- 題號搜尋、主題分類及兩者交集邏輯正常。
- 純類別題不會錯誤提供統計摘要。
- 完全無資料時能阻止計算並說明原因。
- 部分缺資料時只排除無資料組合，不會封鎖整次分析。
- 全選國家、全選波次及四種拆分方式可操作。
- 平均值、中位數、四分位數、標準差、有效人數可切換。
- 圖表與資料檢視可以來回切換。
- 多選題任一順位、指定順位及第 1–3 回答會重新計算。
- 國家與波次呈現方式切換正常。
- 分析紀錄可以載回題目、範圍與分析方式。
- 中英文與三種字體大小切換不會破壞當前分析。
- 狹窄視窗使用大字體時未發現水平溢出或頂部控制重疊。

## 建議實施順序

1. 修正 hydration 錯誤。
2. 合併快速切換造成的分析紀錄。
3. 結果標題改用實際涵蓋範圍。
4. 修正對話中的國家名稱映射。
5. 限制大範圍圖表與量表的單頁資訊量。
6. 改善題目排序與零結果狀態。
7. 補充重新整理後的工作階段保存。
