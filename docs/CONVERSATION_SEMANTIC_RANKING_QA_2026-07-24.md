# 對話語意排序與多語言 QA

日期：2026-07-24

## 問題

舊版題目搜尋主要依靠字詞重合。「民主程度」「民主滿意度」「民主的含義」都含有
`democracy`，因此分數相同時會按題號排序，造成 q91 早於真正測量民主程度的
q96。搜尋也沒有先檢查題目是否支援使用者要求的統計量，所以只支援類別分布的
題目仍可能排在平均分候選之前。

同一問題亦出現在對話狀態：選錯題後再要求平均分，舊版會清除平均分要求並繼續
鎖在原題；「所有國家」等範圍語句在部分狀態下則會被誤當成新題目。

## 新的處理順序

1. 解析並分開保存題目概念、統計量、受訪地區與調查波次。
2. 先按統計能力過濾或降權。例如要求平均分時，只支援類別分布的題目不能成為首選。
3. 再按測量概念排序，區分民主程度、民主運作滿意度、民主含義與民主支持。
4. 候選澄清期間仍保存原始題意與所有已確定條件。
5. 若使用者後續要求目前題目不支援的統計量，重新推薦相容題目，不丟失原始意圖。
6. 統計計算、題目能力與 SQL 均維持確定性；語言模型不得直接產生統計數字。

## LLM 重排設計

LLM 適合用在第二階段的候選重排，而不是取代資料契約：

1. 確定性搜尋先取回 10–20 個候選。
2. 程式先套用題型、統計能力與資料存在性等硬條件。
3. LLM 只判斷使用者描述較接近哪一種測量概念，回傳候選題號、排序與簡短理由。
4. 回傳必須通過既有候選集合與結構驗證；逾時、格式錯誤或低信心時使用確定性排序。
5. 相同標準化查詢可快取重排結果，避免每次對話都增加延遲。

目前公開 Sites 版本沒有可安全使用的雲端模型端點，因此本輪先完成可靠的確定性
基線。日後接入模型時，LLM 重排是可插拔增強，不能成為搜尋、SQL 或統計運行的
單點依賴。

## 已納入的語言範圍

- 繁體、簡體與英文的全部國家／地區說法。
- 繁體、簡體與英文的全部波次、跨波次、逐波、前三波與最近兩／三波。
- 多國家、多波次的增加、刪除、切換與保留。
- 題目談論的國家與受訪者所在地分離，例如「日本人如何看中國」。
- 不存在的美國受訪者樣本會明確拒絕，不把 United States 誤當受訪地區。
- 未選題時輸入範圍條件，只保存條件並繼續詢問題目，不執行無關搜尋。

## 回歸案例

- `日本的民主程度在各波平均值`：q96 排第一。
- `日本人覺得自己的國家有多民主，各波平均`：q96 排第一。
- `mean democracy rating in Japan across waves`：q96 排第一。
- `democracy rating Japan mean by wave`：q96 排第一並保留逐波範圍。
- `所有國家`、`所有国家`、`every country`、`every region`：映射為全部 18 個地區。
- `前三波`、`first three waves`：映射為 W1–W3。
- `最近兩波`、`latest two waves`：映射為 W5–W6。
- 在候選題狀態輸入 `所有國家`：保留候選，不重新搜尋題目。
- 選擇 q91、查看分布後輸入 `改看平均分`：重新提供支援平均分且符合原意的候選，
  q96 排第一。

## 驗證口徑

自動回歸測試驗證 API 狀態、候選順序、統計能力、國家與波次解析；瀏覽器測試另行
驗證實際點選、候選表、結果圖與後續修改是否一致。獨立測試者的舊部署結果、本地
修改結果與最終部署結果分開計算，不互相混用。

矩陣中剩餘兩個嚴格失敗都刻意明示 `q91` 再要求平均分。系統會尊重題號，說明 q91
不支援平均分並提供其合法統計量，而不擅自把明示題號換成語意不同的 q95 或 q96。
這與原始錯誤不同：自然語句「民主程度＋平均值」現在不再提供 q91 作為候選；若
使用者是在自然語句候選中選到不相容題目，原始題意仍會保留並可重新推薦相容題目。
